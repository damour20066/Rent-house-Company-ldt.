# How to Find Your Africa's Talking API Key

1. **Go to**: https://account.africastalking.com

2. **Login** with your account

3. **Click on Settings** (gear icon) in the left menu

4. **Click on API Key**

5. **Copy** the API key that appears (it starts with `atk_`)

6. **Send it to me** so I can configure your server

The API Key looks like: `atk_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
